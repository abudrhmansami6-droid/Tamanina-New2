طمأنينة — استعادة التصميم الأصلي
================================

هذه الحزمة تعيد تصميم تطبيق «عالمي مع الذكر» الذي اعتمدناه سابقاً، ولا تستبدله بالتصميم المبسط الذي أرسلناه لاحقاً.

المحتويات:
- index.html: التطبيق الأصلي مع إضافة دعم التثبيت والعمل دون إنترنت والإشعارات التجريبية.
- sw.js: Service Worker لتخزين التطبيق والعمل دون اتصال بعد أول تحميل ناجح.
- manifest.webmanifest: تعريف التطبيق للتثبيت.
- icon-192.png و icon-512.png: أيقونات التثبيت المطلوبة لأندرويد.
- icon.svg: نسخة متجهية من الأيقونة.

الميزات الأصلية المحفوظة:
- الواجهة الكريمية والخضراء والذهبية.
- اختيار الذكر.
- علبة زجاجية وكرات تسقط بسلاسة في أماكن ثابتة.
- وضع الغابة المستقل، مع عرض حتى 200 شجرة.
- عدادات مستقلة للأذكار، وإجمالي اليوم والإجمالي الكلي.
- الصوت والاهتزاز.
- الأهداف اليومية، الأذكار، الأدعية، الإحصائيات، وصفحة عن التطبيق.
- حفظ محلي عبر localStorage.

الرفع إلى GitHub:
1) افتح مستودع Tamanina-New.
2) احذف/استبدل index.html القديم بالنسخة الموجودة هنا.
3) ارفع جميع الملفات الموجودة في هذه الحزمة إلى جذر المستودع.
4) اعمل Commit changes.

إعداد Netlify:
- Build command: فارغ.
- Publish directory: .
- بعد النشر افتح الموقع عبر HTTPS مرة واحدة وانتظر حتى يكتمل التحميل.
- بعدها اختبر فصل الإنترنت وإعادة فتح التطبيق.

التثبيت:
- في Chrome على Android قد يظهر زر «تثبيت طمأنينة» داخل التطبيق بعد استيفاء شروط المتصفح.
- إذا لم يظهر، افتح قائمة Chrome ثم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية». ظهور «إضافة إلى الشاشة الرئيسية» قد يكون سلوك المتصفح الطبيعي.

الإشعارات:
- يوجد اختبار إشعار وتذكير بوقت محدد أثناء بقاء التطبيق مفتوحاً.
- الإشعارات التلقائية عندما يكون التطبيق مغلقاً تتطلب خدمة Push/خلفية؛ لا تدّعي هذه الحزمة أنها تنفذها دون خادم.

مهم:
- العمل دون إنترنت يبدأ بعد أول تحميل كامل ناجح، وليس قبل أول فتح للموقع.
- Service Worker يحتاج HTTPS (Netlify يوفّر HTTPS) أو localhost.
